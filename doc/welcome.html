Welcome to Stjörnhorn v0.4.0

A node-based image- and video-processing playground.
Documentation GitHub repository Issues Releases

Getting started

  1. Create a flow — type a name and press Create, or open an existing .flowjs.
  2. Drop nodes from the list on the left onto the canvas.
  3. Wire them up by dragging output ports to input ports.
  4. Press Run and watch any inline Display nodes update.

Node categories

Sources

Load still images (JPEG, PNG, CR2) or video files (MP4, AVI, MOV, MKV) as streams of frames.

Filters

Scale, shift, blur, threshold, dither, split/join RGBA channels, overlay with per-pixel alpha, and match templates with NCC.

Sinks

Write frames to image files or encode video (MP4V, XVID) with live preview via the Display node.

What's new in v0.4.0

  • Selectable Neon / Classic theme. Two themes ship side by side: the new Neon look (deep navy canvas, neon-cyan node borders, magenta selection accents, saturated category-coloured rims and outer glows on nodes and wires) and Classic (the pre-restyle flat-grey palette with solid coloured node header strips, no glow). Pick one on the Settings page; the choice persists in settings.json and locks in at next launch. The bundled welcome page and the Port Types legend now follow the active theme — no more grey islands inside a neon UI.
  • Per-node header icon. Every node carries a Material Icons glyph in its header, left of the title, hinting at what it does at a glance. Sources default to play_arrow and sinks to save, with overrides on ImageSource, VideoSource, GaussianBlur, Crop, Display, RGBA Split / Join, and more. The skip / step-over button moved to the right of the title (between the caption and the tick badge) to free the left edge for the icon, and now uses the Material redo glyph instead of the hand-drawn double-chevron.
  • Info button on every non-source node. The "show meta" toggle that started on Display is now a header button on every filter and sink. Clicking it overlays the latest input frame's payload kind, shape, and meta keys — one section per input port — over the body without resizing the node. Source nodes stay unaffected (no input meta to surface).
  • Port legend lives in the Node Documentation dock. The floating "Port types / Port roles" overlay that used to hover in the bottom-left of the canvas is gone. The same swatches and labels now sit in the empty state of the Node Documentation dock under the "Select a node…" hint, and step out of the way as soon as you select a node. The View ▸ Port Legend menu entry and the port_legend_visible setting were removed.
  • Copy button on the message banner. The floating error / notification banner now exposes a Copy button next to Close (with a separator between them so a near-miss can't dismiss the banner), making long stack traces and node errors one click away from the clipboard. Both header buttons grew real hover and pressed highlights so they read as proper buttons.
  • FileSink writes to non-ASCII paths on Windows. Output paths containing umlauts or other non-ASCII characters (the C:\Users\…\stjörnhorn\output\… case) now write correctly. The sink encodes via cv2.imencode and streams the bytes via Path.write_bytes, mirroring the read-side trick already used by ImageSource. Unsupported extensions raise a clear OSError instead of writing a placeholder. VideoSink's analogous Unicode-path issue remains a known follow-up.
  • Flow-run failures no longer abort the process on Windows. A cross-thread Qt teardown race (the FlowRunner being deleted from the wrong thread when a node raised mid-run) is fixed by deferring runner cleanup to QThread.finished. The "Fatal Python error: Aborted" that occasionally killed the app on a node failure is gone.

Tips

  • Recent flows appear on the start page for quick access.
  • User-defined nodes live under ~/.image-inquest/user_nodes/.
  • Run with --flow NAME to jump straight into a saved flow.
  • Press F11 with the output inspector focused to toggle fullscreen preview.
